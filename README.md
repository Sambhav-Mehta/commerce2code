Every time a customer applied for a loan at my company, the system remembered their name, their credit score, their income — instantly.

I approved that feature for 4 years. I never knew what was actually happening behind it.

Here's what I know now.

When a computer needs to remember something, it creates a **variable.** That's it. No magic.

```python
customer_name = "Sambhav"
credit_score = 742
annual_income = 1200000.00
is_eligible = True
```

Each of these is a different *type* of information:

→ `"Sambhav"` — **String.** Any text, always in quotes
→ `742` — **Integer.** A whole number
→ `1200000.00` — **Float.** A number with decimals
→ `True` — **Boolean.** Yes or no. Eligible or not

Every app you've used — Zomato, CRED, PhonePe — is doing exactly this. Storing names, amounts, statuses. In variables.

Once stored, you can display it cleanly:

```python
print(f"{customer_name} has a credit score of {credit_score}")
# Output: Sambhav has a credit score of 742
```

That `f"..."` is an f-string. It slots variables into a sentence. Like mail merge — but for code.

This is literally how your loan approval SMS gets your name in it.
